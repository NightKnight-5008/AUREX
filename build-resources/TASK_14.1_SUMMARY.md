## Technical Notes

### Icon Formats

- **SVG**: Vector source files (scalable, editable)
- **PNG**: Raster images for Linux and intermediate conversion
- **ICO**: Windows icon format (auto-generated by electron-builder)
- **ICNS**: macOS icon format (auto-generated by electron-builder)

### Auto-Generation

electron-builder automatically generates `.ico` and `.icns` files from `icon.png` during the packaging process. Manual creation is optional.

### Platform Requirements

| Platform | Required File | Size | Auto-Generated |
|----------|--------------|------|----------------|
| Linux | icon.png | 512x512 | No |
| Windows | icon.ico | 256x256 | Yes (from icon.png) |
| macOS | icon.icns | 1024x1024 | Yes (from icon.png) |
| All | tray-icon.png | 64x64 | No |
